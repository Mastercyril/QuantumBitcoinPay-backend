# Quantum A.I. Core System
## Standalone AI with Evolutionary Learning and Multi-Personality System

**Creator:** Joseph Dougherty  
**Company:** 13th Chamber LLC  
**Version:** 1.0.0  
**Platform:** Windows (Dell)  
**Storage:** OneDrive + Google Drive Sync

## Features
- 10 Dynamic Personality System with Random Selection
- Evolutionary Learning from Conversation Memory
- Cloud-Synced Memory Banks (OneDrive/Google Drive)
- Neural-Inspired Learning Network
- Ethical/Moral Framework Development
- GUI Chat Interface
- Web Learning Integration

## Installation

1. Extract all files to `C:\QuantumAI\`
2. Double-click `QuantumAI_Installer.exe`
3. Follow installation wizard
4. Launch from desktop shortcut: "Quantum A.I."

## Requirements
- Windows 10/11
- Python 3.9+ (bundled in .exe)
- OneDrive account (configured)
- Google Drive Desktop app (configured)
- 500MB free space minimum

## First Launch
The system will:
1. Create memory banks in OneDrive/Google Drive
2. Generate personality profiles
3. Initialize ethical framework
4. Open chat interface

## Usage
- Type normally in chat interface
- Use instruction panel above chat for commands
- Add website links for learning
- AI remembers all conversations
- Personality changes each conversation
