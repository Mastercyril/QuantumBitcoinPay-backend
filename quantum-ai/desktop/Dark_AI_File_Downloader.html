⚡ Phase 3: CMD Commands & File Creation

STEP 1: Open Windows CMD or PowerShell as Administrator

Press Windows Key + R, type cmd, press Enter

STEP 2: Create the main DarkAI directory

mkdir C:\DarkAI cd C:\DarkAI

STEP 3: Create subdirectories

mkdir core memory\data cloud browser ethics utils

STEP 4: Install Python dependencies

pip install numpy transformers torch google-cloud-storage selenium flask sqlalchemy pydantic python-dotenv

⚠️ This will take 10-15 minutes. Do NOT interrupt.

STEP 5: Download the Python files (provided below)

Click download buttons in the "File Downloads" section below, save to your Desktop or Downloads folder

STEP 6: Move downloaded files to C:\DarkAI

cd C:\DarkAI # Then move each downloaded file to its proper location # Move core files to C:\DarkAI\core\ # Move memory files to C:\DarkAI\memory\ # etc.

Or use File Explorer to drag-and-drop files into their folders

STEP 7: Verify installation

cd C:\DarkAI python main.py --check
