### **4.1 QSAM — Quantum State Amplitude Modulation**

QSAM is the foundational encoding protocol that translates real-world data (molecular structures, cryptographic hashes, transaction data) into quantum circuit representations.

**How it works:**
- Data inputs are mapped to qubit states using RY (rotation-Y) gates with angles derived from the input data
- Each data element is encoded as a specific rotation angle on a designated qubit
- The encoding preserves information fidelity while enabling quantum superposition to explore all possible states simultaneously

**Encoding Formula:**
For each data element *d* at qubit position *i*:

$$RY(\theta_i) \text{ where } \theta_i = f(d_i) + \text{bias}$$

- If the target bit is 1: bias = +0.20 radians (positive amplitude shift)
- If the target bit is 0: bias = −0.20 radians (negative amplitude shift)

**Performance:**
- 5-qubit QSAM circuits explore 32 simultaneous states per execution
- 6-qubit QSAM circuits explore 64 simultaneous states per execution
- Average execution time: 2.4 seconds on IBM ibm_torino

### **6.1 Proof-of-Quantum-Work (PoQW) Consensus Mechanism**

13th Chamber Quantum Crypto introduces a novel **Proof-of-Quantum-Work (PoQW)** consensus mechanism that fundamentally reimagines blockchain mining:

**How PoQW Works:**

1. **Challenge Issuance:** The network generates a cryptographic challenge derived from the previous block hash, current timestamp, and pending transaction Merkle root
2. **Quantum Circuit Construction:** Miners construct a QSAM circuit encoding the challenge data into qubit rotation angles using the proprietary encoding formula
3. **SCORE/ESCORT Enhancement:** Error mitigation and coherence protection layers are applied to maximize measurement fidelity
4. **Quantum Execution:** The circuit is executed on IBM Quantum hardware (or compatible quantum processors), producing measurement statistics over 1,024+ shots
5. **Proof Generation:** The measurement histogram—including dominant state, frequency distribution, and CHSH entanglement parameter—constitutes the quantum proof-of-work
6. **Classical Verification:** Network validators verify the proof by checking:
   - The dominant state matches the expected solution pattern
   - The frequency exceeds the difficulty threshold

   - The entropy profile matches expected quantum distributions (not classical forgery)
